# TermiLyrics 🎧  `Beta`

A terminal-based tool to synchronize lyrics effortlessly. An upgraded variation of \`sptlrx\` engineered to be completely free, rich with features, and highly customizable.

## 🛠️ Project Context & Credits
* **Credits:** Based on original architecture built by **الو | Alo** on Discord. Tremendous thanks to him for providing the foundation framework!
* **Status:** This application is currently in **Beta**.
* **Compatibility:** Natively tested on **CachyOS**. Confirmed working seamlessly with **Spotify** and **YouTube** media players (other players are currently untested).

## ✨ Current Features
* 100% Free backend pipeline mapping.
* Dynamic **ASCII Character modules** that actively adapt and morph based on the emotional context of structural lyrics.

## 🚀 Installation

\`\`\`bash
git clone https://github.com
cd TermiLyrics
python -m venv .venv
source .venv/bin/activate  # Or activate.fish for Fish shell
pip install -e .
\`\`\`

## 💻 Usage

Simply launch the interactive environment loop directly from your terminal:

\`\`\`bash
termilyrics
\`\`\`
