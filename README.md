# TermiLyrics 🎧

A terminal-based tool to synchronize lyrics effortlessly.

## 🚀 Installation

\`\`\`bash
git clone https://github.com/mr1charles/TermiLyrics.git
cd TermiLyrics
python -m venv .venv
source .venv/bin/activate  # Or activate.fish for Fish shell
pip install -r requirements.txt
\`\`\`

## 💻 Usage

\`\`\`bash
python -m lyrics_sync.main
\`\`\`
