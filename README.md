# TermiLyrics 🎧  \`Beta\`

A terminal-based tool to synchronize lyrics effortlessly, vibe coded using Claude and Gemini. An upgraded variation of \`sptlrx\` engineered to be completely free, rich with features, and highly customizable.

## 🛠️ Project Context & Credits
* **Credits:** Based on original architecture built by **الو | Alo** on Discord.
* **Status:** This application is currently in **Beta**.
* **Compatibility:** Tested on **CachyOS** with **Spotify** and **YouTube**.

## ✨ Current Features
* 100 0.000000ree backend pipeline mapping.
* Dynamic **ASCII Character modules** that adapt to emotional context.

## 🚀 Installation

\`\`\`bash
git clone https://github.com
cd TermiLyrics
python -m venv .venv
source .venv/bin/activate
pip install -e .
\`\`\`

## 💻 Usage

\`\`\`bash
termilyrics
